Senior Software Engineer

Equipo Health Inc. · Trivandrum, Kerala

June 2022 — July 2026

  • Built and maintained Django REST Framework APIs for patient records, referrals, e-consultations, and clinical reporting within a microservices architecture, operating across millions of database rows and engineered toward sub-100 ms response targets.
  • Led MySQL performance tuning on high-traffic endpoints using EXPLAIN analysis, composite and covering indexes, and query rewrites — eliminating full table scans and filesorts, and moving complex reporting aggregations into stored procedures.
  • Implemented JWT middleware and role-based permission checks with local token verification, avoiding per-request database lookups; enforced multi-tenant isolation by scoping queries to the group/facility encoded in the token.
  • Developed secure clinical document workflows: file validation, private AWS S3 storage, MySQL metadata, and short-lived pre-signed URLs protected by patient-level authorisation checks.
  • Designed asynchronous, queue-based synchronisation between the core platform and an external care-management system, with event triggers, idempotent upserts keyed by unique event ID, duplicate prevention, and conflict-resolution rules.
  • Built scheduling and eligibility logic for appointment reminders, medication nudges, and follow-ups delivered via the Telnyx API (SMS, IVR, email), with timezone-aware delivery windows and database-level status locks to prevent duplicate sends.
  • Delivered APIs for a React-based operations control panel (facility configuration, referral routing, user permissions) with server-side pagination, filtering, and select_related optimisations to prevent N+1 queries.
  • Improved production traceability with Django middleware generating request IDs and structured JSON logs for AWS CloudWatch Logs Insights; built scheduled Python batch jobs and contributed to Docker, Jenkins CI/CD, and blue-green deployment workflows.

CivicPulse AI

Multi-agent civic grievance & escalation system · Self-directed project

A municipal grievance platform where a Google ADK coordinator agent routes citizen requests to specialist Triage, Knowledge, and Escalation agents. Domain actions stay deterministic: a FastMCP tool server exposes raw-SQL-backed tools for complaint filing, SLA-breach checks, and geospatial duplicate detection (bounding-box pre-filter plus a custom haversine calculation), so SLA maths is never left to LLM inference.

  • Configurable SLA rules by category and priority, with fallback behaviour.
  • RAG over the grievance charter with ChromaDB and Gemini embeddings for grounded, citation-backed answers.
  • Before-model prompt filtering and before-tool audit logging; Django REST views bridged to ADK's async Runner via a background asyncio event loop.
